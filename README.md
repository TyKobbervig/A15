# Week 15 - Forms & Input Systems

## Overview

This week I added a form that allows users to create a PB&J sandwich order. The form collects structured input and uses that information to provide customized feedback after submission.

## Form Features

- Text input for the user's name
- Dropdown menu for jelly flavor selection
- Checkbox for extra peanut butter
- Submit button
- Input validation
- User feedback after submission

## Validation and Feedback

The form checks that a name has been entered before allowing the order to be processed. After submission, the application displays a personalized confirmation message that includes the selected options.

## Reflection

**How does collecting user input change what your application can do?**

Collecting user input allows the application to respond differently based on information provided by each user. Instead of only displaying information, the website can now gather data, process it, and provide personalized feedback. This makes the application more interactive and useful.
